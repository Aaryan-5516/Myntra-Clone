# 🛍️ Myntra Clone – E-Commerce Website

A frontend e-commerce website inspired by Myntra, built using HTML, CSS, and JavaScript. This project replicates the basic shopping experience of an online fashion shopping platform with a user-friendly interface.

## 🚀 Features

- **Home Page:** Clean and attractive shopping homepage.
- **Product Display:** Browse products with images and details.
- **Product Categories:** Organized shopping sections.
- **Shopping Cart:** Add products to the cart and manage selected items.
- **Interactive UI:** JavaScript-based user interactions.
- **Responsive Design:** User-friendly layout across different screen sizes.

## 🛠️ Technologies Used

- HTML5 – Structure of the website.
- CSS3 – Styling and layout.
- JavaScript – Functionality and interactivity.

## 📂 Project Structure

```text
Myntra-Clone/
│
├── css/              # Stylesheets
├── data/             # Project data
├── images/           # Product and website images
├── pages/            # Additional website pages
├── scripts/          # JavaScript files
│
├── index.html        # Main homepage
└── README.md         # Project documentation
```

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Aaryan-5516/Myntra-Clone.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Alternatively, use the **Live Server** extension in VS Code to run the website.

## 🎯 Project Objective

The main objective of this project is to understand frontend web development concepts, including HTML structure, CSS styling, JavaScript functionality, DOM manipulation, and building an interactive e-commerce website.
